# 词形收藏账号竞争修复

基线：`bbfebeba5f2ba8d826ef9130e96447c1b1181e09`（main，PR #34）。
问题出处：PR #29 的 discussion_r4286530040。

## 问题与修复边界

原来的单词收藏、整组收藏在等待词典查询期间切换账号后，会按完成时的账号保存词条、例句和分组；退出后可能落入游客本。整组逐词保存还可能出现部分提交。

- 两个入口在查询前记录账号和操作令牌，完成后重新检查。账号事件、跨标签身份 storage 事件和组件卸载使旧令牌失效；旧请求不能修改新请求的忙碌状态。收到延迟的 A→B→A storage 事件也会取消旧操作。
- `saveWord(entry, now, expectedAccount)`、`setWordFamily(words, family, now, expectedAccount)` 增加可选保护，既有调用签名兼容。受保护读取不触发游客数据迁移。
- `saveWordGroup` 在内存中准备全部词条及分组，检查有效性和账号后向固定账号键写入一次；失败不写半组。已有释义、例句及复习进度保留。配额不足沿用既有的整本内存暂存策略。
- 同步排队使用同一个账号快照，并检查预期账号，避免更新事件中切号后给另一个账号安排同步。

不涉及数据库迁移、RLS、凭据、环境变量、feature flag、出题逻辑或 passage-note 迁移。

## 剩余边界与回退

这是客户端操作归属修复，不重新设计身份认证或整个 localStorage 并发协议。同一账号多标签同时编辑的既有读改写冲突不在本次范围。localStorage 配额不足时仍使用既有内存暂存；关闭页面前尚未持久化的数据风险未改变。

本次不清理历史上可能已错存的数据，因为无法可靠推断词条原归属。切号后取消的收藏需在目标账号重新点击。

交付为独立分支和 draft PR，未合并、未部署生产。合并前可直接关闭 PR；如以后合并，可通过独立回退 PR revert 本修复提交，无数据库回退步骤。
