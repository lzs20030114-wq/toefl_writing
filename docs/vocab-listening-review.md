# 听力单词复习契约

- 一个单词仍只有一张卡，以 `word` 去重。`reviewMode` 是用户单选的 `reading` 或 `listening`；旧卡缺字段时默认为 `reading`。`source` 只记出处，不决定复习模式。
- 阅读 FSRS 状态留在卡片根字段；听力状态单独存于 `listeningState`。切换模式保留两套进度，评分和重置只更新对应模式。`reviewCard` 把当前模式状态投影给队列与复习界面。
- 听力卡优先播放 `listeningContext` 指向的原句音频片段（URL、起止秒数和文本一起存，缺一或范围无效则不用）。无可用片段时，界面使用现有的浏览器单词发音兜底；这条是交互契约，不能把未定位的长音频当作原句播放。
- 两种模式共用每日新词额度；队列先按模式挑词，再按全卡已用额度限制。复习日志带 `mode`，旧日志按 `reading` 处理。生产库需先执行 `scripts/sql/vocab-review-mode.sql`；未迁移时上传失败的日志留在本地重试。
