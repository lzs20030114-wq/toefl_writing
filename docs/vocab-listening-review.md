# 听力单词复习契约

- 一个单词仍只有一张卡，以 `word` 去重。`reviewMode` 是用户单选的 `reading` 或 `listening`；旧卡缺字段时默认为 `reading`。`source` 只记出处，不决定复习模式。
- 阅读 FSRS 状态留在卡片根字段；听力状态单独存于 `listeningState`。切换模式保留两套进度，评分和重置只更新对应模式。`reviewCard` 把当前模式状态投影给队列与复习界面。
- 听力单词复习只播放 `card.display || card.word` 的单词发音，复用现有浏览器 `speakWord`；即使有完整 `listeningContext` 也不创建原句播放器、不显示原句。该数据继续保留，仅内部用于选义与编辑收藏语境释义，无需数据迁移。
- 两种模式共用每日新词额度；队列先按模式挑词，再按全卡已用额度限制。复习日志带 `mode`，旧日志按 `reading` 处理。生产库需先执行 `scripts/sql/vocab-review-mode.sql`；未迁移时上传失败的日志留在本地重试。

## 复习交互（2026-10-03）

- 听力与阅读共用卡面圆角、阴影、间距和键帽样式；退出在左侧，进度按「已答 /（已答 + 剩余）」计算，显示本段与两档累计。顶部保留听词、新词和再次出现标记，评分按钮放在卡片外。
- 每张新问题进入自动播放，包括评分、跳过、同词再次出现和分段继续；翻面、释义保存、父组件统计更新、撤销回已翻面、小结和结束均不触发自动播放。
- 完整听完才解锁翻面。点击卡面或 Enter 翻面；翻面后 Enter / 2 为听懂了、1 为没听懂、Z 撤销。空格播放或重播，在聚焦评分按钮时也只重播；按钮上的 Enter 保留原生操作。小结上的空格 / Enter 继续下一段（聚焦按钮时交给原生按钮）。
- 重复按键、修饰键、输入区域、可编辑区域及已处理事件不触发复习快捷键。编辑释义时不抢快捷键；菜单打开时空格仍可重播，Escape 或点击卡面关闭菜单。
- 单词正常完整播放结束才解锁；发音失败或不可用时提示重试或跳过，点击播放或空格可重试。停止、暂停、退出、分段与换卡令旧回调失效，失败后的迟到成功也不能解锁。播放完成前不泄露词形、音标和释义，原句在前后两面均不显示。
- 与阅读一样提供暂停复习；编辑释义仅在答案面开放，保留账户校验、当前语境释义写回和错误提示。听力只考听懂，不加入拼写步骤。
- 当前单词方案组件行为测试覆盖自动播放与不重播边界、快捷键和焦点、发音失败/不可用/过期回调/暂停不解锁、分段存档与撤销，以及即使带有效原句数据也仅播单词且不显示句子。此前主线程桌面与 390px 视口（可见区域 375px）无横向溢出、真实 WAV 原句播放及分段次数检查属于已被替代方案的历史验证。真实浏览器 speechSynthesis（未模拟回调）曾验证单词自动播放、完整结束解锁及无报错；本次简化后的真实浏览器复验由主线程完成，未验证音色与不同设备发音质量。

- 当前单词方案已在真实浏览器实测：两张携带有效 `listeningContext` 的卡片，`speechSynthesis.speak` 文本仅为 apple / forest，HTML 音频 play 次数始终为 0；自动播放、空格重播、Enter 翻面且无原句、2 换卡、Z 撤销均通过。此检查不验证发音质量。
