# 中文找词与整组学习

入口是首页 `/?section=vocab`，旧 `/vocab-notebook` 仍转入同一个首页单词本。中文找词放在词根查询后，复用单词本外壳、导航和复习组件。

输入中文词，AI 返回可表达该含义的英文词、各词使用场景、区别和例句。AI 请求复用现有 `/api/ai`，沿用认证、限流、配额与错误处理。用户可单词收藏或整组收藏；词卡经既有本地优先存储和 `/api/vocab` 云镜像同步，保留已有词的学习进度。

查询和辨析历史仅保存在当前账户本机缓存，最长 30 天、最多 12 组；不会创建云端分组表。卡片仍是一词一卡，中文找词来源显示为「中文找词」。无需 SQL 迁移、无需新增 feature flag、无需新增环境变量；AI 使用项目现有 DeepSeek 配置。

「整组学习」是用户主动发起的额外练习，可包含未到期词，也不受今日新词数量限制；它不会修改每日额度设置、FSRS 参数或词卡原有阅读/听力模式。启动时重新读取当前账号卡片，按指定模式投影对应 SRS 轨道，并排除重复、缺失、软删除和暂停词。未入库的词须先收藏。

组学习复用原有阅读或听力复习的评分、撤销和回访流程，真实评分仍更新该轨道的 SRS 与复习日志，也会影响当天学习统计。组学习不写入、不删除日常阅读/听力复习断点；离开后回到单词本，最近查询从本机缓存恢复。查询中或练习中切换账号时，旧账号回调不得写入新账号。

端到端验证采用隔离的测试浏览器与模拟 AI 响应，覆盖中文查询、辨析显示、单词及整组收藏、整组练习和刷新恢复，并检查 1440px 桌面与 390px 手机宽度。这组浏览器测试不使用真实用户数据、不调用付费 AI；另有独立真实 provider 验证，确认中文「妨碍」请求返回的 8 个表达可完整解析。
