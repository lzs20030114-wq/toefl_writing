# 学术阅读干扰项标注规则 v1.2

目的：给学术阅读（AP）每道选择题的**每个错误选项**打一个可追溯的结构化标签，说明「这个选项错在哪」。
标签描述的是**选项本身的缺陷**，不是学生为什么选它；学生的错因不由标签推断。

每个干扰项输出：
- `label`：从下面对应题型的类别表里选**一个**主类别（不许自造）
- `evidence`：判定依据的原文句号，如 `["S7"]`（可多句；「原文未提」时写最接近的那句，并在理由里说明原文只说到哪）
- `quote`：从依据句里**逐字**摘一段英文原话（≤25 词）
- `reason`：一句中文，说清「选项说了什么 vs 原文说了什么」
- `confidence`：high / medium / low（两个类别都说得通时写 low，并在 `alt` 写第二候选）

## A. 意义类题（factual_detail、inference、rhetorical_purpose、main_idea、paragraph_relationship、sentence_selection）

| 类别 | 判定标准 |
|---|---|
| 与原文相反 | 选项的说法和原文明确相反（肯定/否定、增/减、支持/反对颠倒） |
| 原文未提 | 原文找不到支持，也找不到反驳；选项引入了原文没有的信息 |
| 偷换概念 | 用了原文的词或信息，但把关键概念、对象或程度换掉了，或把原文属于另一个主体、另一段、另一个事物的信息安到这里（原「张冠李戴」并入此类） |
| 范围扩大或缩小 | 原文限定的范围被放大（all/always/only 等绝对词）或缩小 |
| 过度推断 | 方向和原文一致，但推得比原文能支持的更远（推断题最常见） |
| 因果倒置 | 原文的因果、先后或条件关系被颠倒或错接 |
| 答非所问 | 选项本身符合原文，但不回答题干（目的题里常见：内容对、作用不对） |

判定顺序：先看选项内容是否符合原文 → 符合则多半是「答非所问」；不符合再在其余六类里选最贴切的一个。

## B. 反向题（negative_factual：选「原文没有提到 / 不正确」的那项）

干扰项是**原文确实提到的**选项。标签固定为「原文提到」，`evidence` 写它在原文的出处。

## C. 词汇题（vocabulary_in_context）

| 类别 | 判定标准 |
|---|---|
| 常见义非语境义 | 是这个词常见的意思，但不是这里的意思 |
| 形近或词根干扰 | 和目标词拼写、词根相近而被误认 |
| 不符合语境义 | 代入原句后意思不通、与上下文矛盾，或只是和话题相关但不是这个词的意思（原「语境不通」「语境相关但不等义」合并） |

## D. 指代题（reference）

| 类别 | 判定标准 |
|---|---|
| 就近名词误指 | 选了离代词最近、但语法或语义上不匹配的名词 |
| 语义不通 | 代入后句意不通 |

## E. 插入句题（insert_text：选项是位置 [A][B][C][D]）

| 类别 | 判定标准 |
|---|---|
| 指代或话题不衔接 | 插入句里的代词/this/such 等在该位置找不到前文对象，或该位置的话题与插入句不衔接、出现得太早或太晚（原「指代断裂」「话题顺序错」合并） |
| 衔接词不对应 | 插入句的转折、递进、举例等连接词和该位置前后关系不符 |
| 打断逻辑链 | 插在两句紧密相连的句子之间，把原有推进打断 |

## 规则外的情况

如果确实没有任何类别贴切，label 写「其他」，并在 `new_rule` 里用一句话描述你建议的新类别（名称 + 判定标准）。不要为了凑类别硬套。

## 成品数据里的置信度

`data/realBank/reading/distractor-labels.json` 里每个选项都有 `text`（选项完整文案，逐字和题库比对，用来发现重建题库后选项文案变了或互换了）和 `confidence`：两票一致取两票中较低的一档；终审采纳某一票取那票的（最高记 medium）；终审另判记 medium；待老师定记 low。不是 high 时，`alt` 写另一票或标注员给的第二候选类别（有的话，且必须在该题型的类别表里）。

## 两票怎么出

- 第一票（Sonnet，中等强度）：先判类别，再找依据句。
- 第二票（Sonnet，高强度）：先找依据句，再判类别；选项顺序倒过来给（插入句题不打乱）。
- 两票类别相同且依据句有交集 → 采用。
- 不一致，或任一票标了「其他」→ 第三票（Opus）终审裁决；裁决仍拿不准的标「待老师定」。
- Opus 终审可以提出规则里没有的新类别（写在 `new_rule`），汇总成「新条例候选」清单，之后再研究要不要加。

## v1.1 补充：「原文未提」细分（2026-10-13 用户同意）

原标「原文未提」的干扰项再细分为四个子类（v1.2 起：「常识干扰」标准收紧、新增「空泛套话」，均经用户同意）（`sublabel`），大类仍是「原文未提」：

| 子类 | 判定标准 |
|---|---|
| 常识干扰 | 选项内含的命题在现实中确实成立（或是该领域公认的事实），考生不读原文、凭背景知识就会觉得对，但原文没有提到。只是听着合理的推测、或把原文对象挪到别处的说法，不算此类（归沾边无据） |
| 沾边无据 | 选项用到了原文出现的对象或话题，但它说的具体内容原文没有任何支持（也没有反驳），也不是现实常识 |
| 毫不相关 | 选项的对象或内容在原文里根本没有出现，也不是这个话题下的常识；读过原文的考生几乎不会选 |
| 空泛套话 | 放在几乎任何学术话题上都说得通的泛泛表态（需要更多研究 / 难以精确衡量 / 是重要或根本问题），原文未提，既非具体领域常识、也不针对原文具体内容（可以点名原文的话题对象，如「X 需要进一步研究」，只要说法本身是套话就算此类） |

判定顺序：先问「是否是放在任何学术话题上都成立的泛泛表态」→ 是则「空泛套话」；再问「是否现实中确实成立、凭背景知识就会觉得对」→ 是则「常识干扰」；否则问「是否用到了原文出现的对象或话题」→ 是则「沾边无据」；否则「毫不相关」。
如果细看发现其实不属于「原文未提」（例如原文其实有反驳 → 与原文相反），在 `relabel` 写正确大类，sublabel 留空。
